本版把构建与扫描工具链升到修复版本，关掉 12 条可达的 Go 标准库缺陷，中继行为与协议不变。

## 问题修复

- **标准库缺陷**：从 Go 1.25.13 到本版之间的 12 条可达告警已在 Go 1.27.3 全部关闭，模块与容器构建镜像一并升级。
  涉及 HTTP/2 内存耗尽与流控、HTTP/1 CONNECT 后的连接错位、`crypto/tls` ECH 校验、`crypto/x509` 中间证书信任、`html/template` 转义与 MIME 头解析。
- **构建镜像**：构建阶段改用 `golang:1.27.3-alpine`，摘要已按多架构 index 固定，来源记录在溯源文档里。
- **扫描器**：`govulncheck` 从 `v1.1.4` 升到 `v1.9.0`，旧版本在 Go 1.27 语法树上会直接失败，等于门禁无法出结论。

协议版本仍为 `0.1.0`，本版不需要同步升级 Android 或 Chrome 扩展。

升级只替换容器镜像，`data/`、`authority/`、`backups/` 三个目录原样保留，数据库结构没有变化，已有工作区、成员与设备无需重新加入。升级前仍建议先把这三个目录复制一份。

详细说明见 [发布溯源](https://github.com/huaxianyan/SevenMirror-Server/blob/v0.1.2/docs/server-release-provenance.md) 与 [部署指南](https://github.com/huaxianyan/SevenMirror-Server/blob/v0.1.2/docs/deployment.md)。
