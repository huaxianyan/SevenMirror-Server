把设备名册的对齐和按钮样式收齐：展开设备不再带动旁边的列，页面上的按钮统一成一种。

## 改进

- **列宽固定**：表格改成固定布局，设备、最近活动、操作分别为 52%、22%、26%，展开或收起详情都不会让「最近活动」左右移动。
- **按钮统一**：退出、刷新、重命名、移除与浮层里的关闭都使用与「添加设备」相同的填充主色；菜单内的最终确认仍保留危险色，避免一个对话框里出现两个一模一样的选择。
- **刷新只在空态出现**：待处理申请没有内容时，「刷新」跟在标题右侧；一旦有待处理申请，它就不再出现，避免在能直接处理时提示刷新。

协议与部署方式不变，升级只需替换镜像，`data/`、`authority/`、`backups/` 原样保留。
