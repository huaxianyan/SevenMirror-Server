SevenMirror Server is the relay for the SevenMirror notification mirroring
system. It routes end-to-end encrypted notifications between your phone and your
browsers and holds the workspace authority that decides which devices may join.
This is the first tagged release.

## 主要更新

- **Opaque ciphertext relay**: the server forwards per-recipient encrypted
  payloads and never parses, logs or persists notification content. It can see
  ciphertext sizes and delivery timing, and nothing else.
- **Authority-signed membership**: device identity, role and revocation come from
  one Ed25519 workspace authority whose private key stays in operator custody.
  Approval, rename and removal are the only operations that need it.
- **Private admission by default**: there is no open registration. A device joins
  with a short-lived one-time code and only becomes active after approval.
- **Durable delivery with cumulative cursors**: recipient-specific delivery,
  bounded retention and authority-certified snapshot recovery keep a client that
  was offline converging without replaying what it already confirmed.
- **One image, three roles**: the container ships the relay, the admin CLI and the
  management console. Only the relay starts by default, and only the management
  containers mount the authority key directory.
- **Deployment assets**: a Compose file, a first-run guide, loopback-only
  publishing, a reduced access-log baseline for Caddy, and a consistent
  workspace backup and restore path.

Upgrade by pinning the new image digest and recreating the relay container;
devices reconnect a few seconds later. A release that changes only documentation
produces identical binaries, so check the build inputs before restarting.
