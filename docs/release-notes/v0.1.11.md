管理端「设置」页多了一个可以自己贴 CSS 的地方，用来调内置样式没有覆盖到的排版。

## 新功能

- **自定义样式**：设置页的输入框可以贴一段 CSS，应用到管理端页面。首次打开预置一套与浏览器扩展一致的排版样式，另有「恢复默认」与「清空」，保存后才生效。内容记在当前浏览器里，不影响服务端记录、设备状态或同步行为。

## 改进

- 登录页、初始设置页也加载同一份自定义样式脚本，登录前后排版一致。
