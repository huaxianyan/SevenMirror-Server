这一版把管理端的操作细节收干净：添加设备改成弹出的浮层，展开收起有过渡，次要按钮统一了样式。

## 改进

- **添加设备改成浮层**：点右上「添加设备」弹出表单，不再把名册往下挤；关闭、Esc 或点浮层外面都能收起，控制台仍然不需要脚本。
- **展开收起有过渡**：设备详情、重命名与移除的确认表单在展开时按高度过渡，不再整块跳一下；系统开启「减少动态效果」时保持瞬时。
- **待处理申请可刷新**：分组标题旁加「刷新」，加入申请由客户端发起，控制台不会自己去轮询。
- **按钮统一**：退出、刷新、重命名、移除共用一种次要按钮样式与高度，填充色只留给页面唯一的主动作。

功能、接口与部署方式不变，协议版本仍为 `0.1.0`；升级只需替换镜像，`data/`、`authority/`、`backups/` 原样保留。

详细行为见 [部署指南](https://github.com/huaxianyan/SevenMirror-Server/blob/v0.1.5/docs/deployment.md) 与 [发布溯源](https://github.com/huaxianyan/SevenMirror-Server/blob/v0.1.5/docs/server-release-provenance.md)。
