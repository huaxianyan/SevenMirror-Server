本版修复首次部署与重复启动的问题，并让容器健康检查反映中继的实际就绪状态。

## 主要更新

- **启动配置**：部署文件提供自动初始化步骤，已有工作区重复初始化时保持原有身份。
- **数据目录**：服务收紧状态目录权限，并拒绝把根目录或当前目录作为需要收紧的目标。
- **健康检查**：`/readyz` 实际查询 registry，读取失败返回未就绪。镜像提供内置探针。
- **TLS 探针**：使用配置的证书链验证本地监听端，支持绑定地址与证书域名不同的部署。
- **发布版本**：Release 标签与协议版本独立，标签发布自动构建并分发镜像。

协议版本仍为 `0.1.0`，本版无需同步升级 Android 或 Chrome 扩展。
升级前备份工作区数据与权威密钥，使用新镜像摘要更新中继和管理端。

详细说明见 [发布溯源](https://github.com/huaxianyan/SevenMirror-Server/blob/v0.1.1/docs/server-release-provenance.md) 和 [部署指南](https://github.com/huaxianyan/SevenMirror-Server/blob/v0.1.1/docs/deployment.md)。
