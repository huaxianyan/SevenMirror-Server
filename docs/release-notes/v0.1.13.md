管理端与服务端现在分开发布：只改管理界面时，不必再发一次服务端镜像。

## 新功能

- **两条发布线**：服务端仍是 `vX.Y.Z`，管理端改为 `admin-vX.Y.Z`，各发各的镜像（`sevenmirror-server` 与 `sevenmirror-admin`）。两边都改就两个标签一起打。
- **管理界面文件从二进制里拿出来**：模板与样式改从 `/app/web` 读取，可以直接挂载覆盖。改文案或样式只需替换文件后重启管理端容器，不必重发镜像。

## 改进

- 服务端镜像不再包含管理界面文件，镜像体积随之变小。
- 发布记录、溯源与镜像校验脚本按组件区分，两个镜像各自留痕。

## 注意

- 数据库模式升级时两个镜像必须一起更新：旧管理端会拒绝打开比它更新的库，这是有意的保护。
- 部署文件现在有两个镜像摘要（`x-server-image` 与 `x-admin-image`），只换其中一个即可只升级一半。

详细行为见 [部署指南](https://github.com/huaxianyan/SevenMirror-Server/blob/v0.1.13/docs/deployment.md) 与 [发布溯源](https://github.com/huaxianyan/SevenMirror-Server/blob/v0.1.13/docs/server-release-provenance.md)。
