管理端从这里开始单独发版，装的是管理界面自己的镜像。

## 新功能

- **独立的镜像与标签**：管理端发布为 `sevenmirror-admin`，标签用 `admin-vX.Y.Z`。服务端下一版之后，改管理界面就只发这一个镜像。
- **界面文件可挂载**：模板与样式从 `/app/web` 读取，改用挂载目录后，只调整措辞或样式不必重新构建镜像。

## 注意

- 两个镜像读同一个数据库。服务端升级了数据库模式后，旧管理端会拒绝启动，那次两边要一起发。
- 与 `v0.1.13` 同时发布，两者可以配套使用；本版不含服务端中继的任何改动。

详细行为见 [管理端说明](https://github.com/huaxianyan/SevenMirror-Server/blob/admin-v0.1.0/docs/admin-web.md)。
