这一版把管理端的设备页从一堆卡片改成名册：每台设备一行，需要时再展开细节。

## 改进

- **设备表格**：待处理与已接入都改成表格，列是设备、最近活动、操作。设备名下面是平台与状态，时间与权限位收进名字旁的展开项，行内不再堆控件。
- **操作归位**：重命名与移除收在操作列，点开才出现确认表单，不会一进页面就看到一片按钮。
- **打开不跳位**：控制台内容居中，之前只有设备页长到出现滚动条，页面会横向跳一下；现在滚动条位置固定预留。

功能、接口与部署方式都没有变化，协议版本仍为 `0.1.0`，不需要同步升级 Android 或 Chrome 扩展。升级只需替换镜像，`data/`、`authority/`、`backups/` 原样保留。

详细行为见 [部署指南](https://github.com/huaxianyan/SevenMirror-Server/blob/v0.1.4/docs/deployment.md) 与 [发布溯源](https://github.com/huaxianyan/SevenMirror-Server/blob/v0.1.4/docs/server-release-provenance.md)。
